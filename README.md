# Blockchain Full-Stack Assessment

## Tech Stack
- Frontend: React + TypeScript + Vite
- Backend: Node.js + Express
- Smart Contract: In-memory JS simulation

## Fixes Implemented
- BigInt JSON serialization fixes
- Withdraw access control (owner-only)
- Latest blocks slicing fix
- Global Express error handler
- Frontend balance normalization

## How to Run
npm install
npm run dev

Frontend: http://localhost:5173
Backend: http://localhost:3001
